Linear Regression Educational Examples
Overview
This project provides a comprehensive pedagogical guide designed to help students understand the core concepts of linear regression using Python. It bridges theoretical 
foundations with practical implementations, covering simple linear regression, model diagnostics, residual visualizations, and multi-variable analysis.

1. Simple Linear Regression and Intercept Estimation
This section covers the fundamentals of fitting an Ordinary Least Squares (OLS) regression model with a single independent variable. It emphasizes the structural necessity of adding
 a constant term to the dataset so the algorithm can accurately compute the intercept alongside the slope, avoiding common indexing
errors during parameter extraction and summary generation.

3. Visualizing Predictions and Residual Errors
To build students' geometric and intuitive understanding of regression, this part focuses on graphical representation. It explains how to plot actual observed data points against
the model's fitted prediction line and how to highlight the vertical distances (residuals). This visual layout clearly demonstrates the exact location and magnitude of prediction errors,
 making model evaluation transparent for learners.

5. Multiple Linear Regression Analysis
This module transitions students from single-variable models to multivariate problems. Using real-world educational indicators—such as study hours, attendance percentages,
completed assignments, previous scores, and sleep hours—it demonstrates how to incorporate multiple features simultaneously into an OLS regression framework to predict student
outcomes and analyze complex relationships.
